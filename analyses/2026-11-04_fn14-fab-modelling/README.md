## 问题

P4A8 阻断 TWEAK、PDL192 几乎不阻断（均已读原文确认）。**模型能否重现这个差异？**
假说 H：差别在于表位是否与 TWEAK 接触面**重叠**。

这是本项目第一个**有实验标准答案**的结构检验——不是预测未知，而是看模型能否解释已测定的事实。

## 关键输入：两个抗体的完整可变区序列

  **同页印有核苷酸序列，翻译后与图像读数在 1–97 位完全一致**——独立交叉验证。

## 事先注册

`docs/preregistration.md`，阈值在提交作业前写死：主判定是 Fab 表位与 TWEAK 接触集的重叠残基数
（支持 H：P4A8 ≥ PDL192 的 2 倍且 P4A8 ≥ 4、PDL192 ≤ 3；反对 H：PDL192 ≥ P4A8）。
并事先写明了会削弱结论的风险（AF3 对抗体–抗原复合物准确性较低、人源化序列与竞争实验用的变体不完全对应等），
以及"两个条件都低 iptm → 无结论"是可接受的结果。

## 结果（详见 `docs/M3_results.md`）

**检验失败，H 未被检验。** 两种失败方式都可诊断：

| 条件 | `chain_pair_iptm` 过 0.50 门槛 | 外部核对 |
|---|---|---|
| F1 PDL192 | **0 / 25** 个样本 | （模型不可用，不作核对） |
| F2 huP4A8 | **25 / 25** 个样本 | Table 2 所列 Fn14 残基 **1 / 10**（仅 W42）；事先注册的重链 CDR 子集 **0 / 6**；Table 2 的 **15 组指定配对只对上 W42–Y34**（3.45 Å） |

Fn14 自身折叠在两个条件下都正确（CRD RMSD 1.62 / 1.67 Å），不可用的只是 Fab 相对抗原的位置。
huP4A8 的状态是 **PRE-REGISTERED ipTM GATE PASSED / PARTIALLY CONSISTENT / NOT VALIDATED**——
若不做外部核对会被整体当成可信表位模型，但它也**不是全错**：
- **W42–Y34（CDR-L1）这一对被重现**（3.45 Å），而 W42 正是 P4A8 功能上最关键的残基（W42A 失去结合）；
- 其**柄区接触 68–73** 与 Bayer WO2014198817A1 的截短实验方向一致（P4A8 需要 CRD 之外的 69–80）；
- 但 **N 端 28–35 的全覆盖没有任何独立支持**，仍是最可疑的一段。

描述性数字的方向**不利于** H（若忽略门槛直接套主判定，落入"反对 H"一支），但本次不以此为结论；
该方向在四种 TWEAK 接触集定义下都不翻转（`tables/M3_contactset_sensitivity.tsv`）。

**注意不要读成"假说已被否定"：** 没有判定结果，不等于结论为否。

**因此：** 本次不产生任何可用的 Fab 表位，`fn14_binders.tsv` 的证据等级不变。
不继续调 AF3 参数去"做对"——那是在已知答案下拟合，违背事先注册的意义。
