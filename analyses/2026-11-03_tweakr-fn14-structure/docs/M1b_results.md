# M1b 结果：AF3 预测的 Fn14 胞外区 vs 2KMZ

**判定：PASS**（判定条件 C，依据 `M1b_preregistration.md` 及其修订 1；标准未在看到结果后改动）。
评估脚本 `code/af3_M1b/evaluate_M1b.py`；表格在 `tables/M1b_{summary,per_sample,templates}.tsv`。

## 模板核对（BLOCKED 规则）

| 条件 | 实际使用的模板 | 其中的 Fn14 实验结构 |
|---|---|---|
| A（默认截止 2021-09-30） | 2EQP、2KN0、4KT1 ×2 | 2EQP、2KN0 |
| B（2011-06-01） | 2EQP、1XU1、2EBR、1VVC | 2EQP |
| **C（2007-12-31）** | 1XU1、2EBR、1VVC、1DAX | **无** |

C 的四个模板（PDBe 标题）：1XU1 = APRIL–TACI 晶体结构（TNFR 家族同源物，允许）；2EBR = Nup153 zf-RanBP 结构域；
1VVC = 痘苗病毒补体控制蛋白；1DAX = 铁氧还蛋白。后三者与 Fn14 无关。因此 C 不被 BLOCKED。

## 限制（claim ceiling）

1. **训练集暴露不能排除。** AF3 的训练数据含 2021-09-30 之前的 PDB，2KMZ（2011）和 2EQP（2008）都在其中。
   M1b 证明的是"不输入 Fn14 模板时，AF3 能重现 CRD 折叠"，**不是**从头预测；模型可能记得这个结构。
   注册时没有考虑到这一点，在此补记。
2. 单体、无配体：M1b 不检验 TWEAK 结合界面，也不检验膜上取向。
3. 不含 CRC 数据。

**对 M2 的含义：** 可以进入 M2。但 M2 的界面解读仍要以实验突变数据（D45/K48/M50/D62）为准，
不能只依据 AF3 的置信度。
