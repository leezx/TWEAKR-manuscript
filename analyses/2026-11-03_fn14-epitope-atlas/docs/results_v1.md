# 结果 v1：Fn14 治疗性抗体 / ADC 表位清单与结构映射

**2026-11-03。** 规则见 `design.md`（commit `afd15b4`，早于任何检索）。表格：`tables/fn14_binders.tsv`（11 条直接结合 Fn14 的药物）、
`tables/tweak_ligand_binders_excluded.tsv`（靶向配体、单独列出）、`tables/epitope_residue_geometry.tsv`（结构映射）。

## 1. 清单的主要结论：残基级表位信息几乎不存在

11 条直接结合 Fn14 的药物中，按事先定好的分级：

| 级别 | 含义 | 条数 |
|---|---|---|
| E1 实验复合物结构 | 可直接读出接触残基 | **0** |
| E2 实验表位定位 | 定点突变等 | 2（enavatuzumab/PDL192、P4A8，且是同一个实验） |
| E3 竞争结合 | 只能说明可能重叠 | 3（18D1、4G5、5B6） |
| E4 仅知结合胞外区 | 不上结构图 | 6 |
| E5 预测 | 本项目尚未做 | 0 |

**没有任何一个 Fn14–抗体复合物的实验结构。** 整个公开文献里，能落到残基的表位约束只有一组：
Trebing 2014（PMID 24135629）报告 PDL192 与 P4A8 **不能**有效结合人 Fn14 的 **W42A** 和 **R56P** 点突变体，
而三个羊驼来源抗体（18D1、4G5、5B6）都能。这是本清单中唯一的 E2 证据。

这直接回答了 B32 之后的问题：**现在还不具备做大规模抗体–Fn14 结构建模的输入条件**，因为公开的 VH/VL 序列基本没有
（本轮检索到的论文都没有给出序列；专利未检索）。清单的价值在于指出这个缺口，而不是立刻建模。

## 2. 把仅有的 E2 表位残基映射到 M2 模型

用 B32 冻结的 M2-C 第一名模型（`code/map_epitope_residues.py`，三个 Fn14 拷贝分别计算）：

| 残基 | 证据 | 到 TWEAK 最短距离 | 在 ≤5 Å 界面内 | 游离受体 SASA | **被 TWEAK 埋掉的 SASA** |
|---|---|---|---|---|---|
| **W42** | E2（PDL192/P4A8） | 6.28–6.35 Å | 0/3 | 84 Å² | **0 Å²** |
| **R56** | E2（PDL192/P4A8） | 6.86–6.89 Å | 0/3 | 225 Å² | **0 Å²** |
| D45 | TWEAK 结合（参照） | 2.74–2.75 Å | 3/3 | 132 Å² | 111 Å² |
| K48 | TWEAK 结合（参照） | 2.54–2.55 Å | 3/3 | 102 Å² | 61 Å² |
| M50 | TWEAK 结合（参照） | 3.71–3.77 Å | 3/3 | 50 Å² | 27 Å² |
| D62 | TWEAK 结合（参照） | 3.05–3.09 Å | 3/3 | 49 Å² | 9 Å² |

**模型给出的图像：** W42 与 R56 都**不在** TWEAK 接触面上，而且 TWEAK 结合后它们的溶剂可及面积**一点也没有被遮住**
（0 Å²，与四个结合残基被埋掉 9–111 Å² 形成对照）。W42 紧贴 TWEAK 足迹（距 D62 4.9 Å、距 D45 6.1 Å），
R56 则远一些（距 D45/D62 11–16 Å）。两者相距 14 Å，一个 Fab 的足迹（约 800 Å²，跨度 20–30 Å）足以同时覆盖这两点。

**由此得到的可检验假说（不是结论）：** 如果 W42/R56 确实位于 enavatuzumab/P4A8 的表位内，那么该表位与 TWEAK 足迹
相邻但不重叠，预测这类抗体**可以在 TWEAK 已结合的受体上结合**（非竞争性）。这与它们"单独不激动、交联后强激动"
（Salzmann 2013）的行为相容：它们更像交联剂而不是阻断剂。相反，18D1/4G5 能阻断 TWEAK 却不受 W42A/R56P 影响，
提示它们的表位落在 TWEAK 足迹本身，与 PDL192/P4A8 是两个不同的位点。

**检验方式：** 直接做 enavatuzumab 与 TWEAK 的竞争结合实验，或解析复合物结构。清单中目前**没有**任何一篇文献
报告过 enavatuzumab 与 TWEAK 的竞争实验结果。

## 3. 对 ADC 方向最相关的一条

**ITEM-4**（FNB-004）是清单里唯一有明确内吞证据的抗体：ITEM4-rGel 在 Fn14 阳性 T-24 细胞中 2 小时内特异内吞，
Fn14 缺失的成纤维细胞中不内吞（共聚焦，Zhou 2011）。其他所有条目的内吞性质在本轮读到的文献中都没有建立。
对"能有效结合并内吞、但不激活 Fn14"的 ADC 抗体筛选而言，这既是最有用的先例，也说明候选池非常小。

另一条与 CRC 直接相关：STX2a-PE15-P4A8（FNB-011）在结直肠癌和肺癌细胞上报告过活性。

## 4. 限制（claim ceiling）

1. **继承 B32 的全部限制。** M2-C 是预测模型，不是实验测定的复合物结构。上表所有几何量都是模型内的量。
2. **两个残基不等于一个表位。** W42A/R56P 只是两个点突变；Fab 的真实足迹要大得多，仍可能与 TWEAK 发生空间冲突，
   "不遮挡"只说明这两个残基本身没有被埋。
3. **突变导致结合丧失 ≠ 直接接触。** W42 只有约 1/3 暴露（84 Å²），W42A 也可能是通过局部折叠改变间接影响结合；
   R56 高度暴露（225 Å²），更可能是直接接触。这与四个 TWEAK 结合残基的同类限制一致。
4. **证据来自摘要。** Trebing 2014 全文未能取得（Europe PMC 非开放获取），W42A/R56P 对 PDL192 与 P4A8 各自的
   影响程度无法分开；"PDL192/P4A8 结合丧失"是按摘要中 "In contrast to ... PDL192 and P4A8" 的表述理解的。
5. **检索不完备。** 只检索了 PubMed/ClinicalTrials.gov；专利未检索，因此"VH/VL 未公开"应读作"本轮未在文献中找到"，
   不等于不存在。二手数据库未用作 verified 依据。
6. 不含任何 CRC 数据；不支持关于任何抗体在 CRC 中效果的主张；不涉及正常组织表达与安全窗口。

## 5. 下一步（按价值排序）

1. **检索专利**，确认 enavatuzumab、BIIB036、P4A8 的 VH/VL 是否公开。这是决定能否做 Fn14–Fab 结构预测的唯一门槛。
2. 若有序列 → 对 1–2 个抗体做 AF3 Fn14–Fab 预测（标为 E5，虚线），与 W42/R56 的约束比对。
3. 取得 Trebing 2014 全文，分开 PDL192 与 P4A8 的突变体数据。
4. Fn14 正常组织表达与膜丰度（ADC 安全窗口），属另一条线。
