# 冻结标准：这份 atlas 什么时候算"完整到可以合并"

**2026-11-04 写定**，起因是本项目向审核方提出的问题：前三轮每轮都能找到新的专利或文献，
但核心结构结论三轮未变——那么"完整"的标准是什么，才不至于无限扩检索？

## 范围定义（取代"穷尽"这个不可验收的目标）

> **Publicly disclosed Fn14-targeting therapeutic binder and construct atlas —
> literature and patent evidence through 2026-11-04.**

即：**截至指定日期，公开文献与专利中可识别、可追溯的** Fn14 靶向治疗性 binder 与构建体。

绝对完整性不是可验收的目标，因为：很多抗体只出现在专利中；有些序列从未进入论文；有些研究只给 clone ID；
同一抗体会被重命名、人源化或做成不同 payload；企业项目可能从未公开；新专利持续出现。

## 冻结条件

1. 预先确定的检索渠道与同义词覆盖已完成（Fn14 / TWEAKR / TNFRSF12A / CD266 × 文献 + 临床试验 + 专利）。
2. 已做过一次 citation chasing 与专利族补检。
3. 此后**连续两轮定向查询没有新增独立资产**（"独立资产"= 新的 binder lineage，不是同一抗体的另一个公开文本）。
4. 每条记录都有可追溯出处，且 `verification_status` 如实反映本项目是否亲自核实。
5. 证据分层（A 同行评议实验 / B 专利报告实验 / C 专利权利要求）已标注，冻结的 E1–E5 只统计 A。
6. 已知的未核实项在文档中逐条列出。

## 重新开启的条件

只有出现以下之一才重开，而不是因为又发现了一篇文献：

- 新的**独立** Fn14 binder lineage；
- 新的**临床**开发资产；
- 新的实验表位或复合物结构；
- 新的直接竞争或内吞实验，且足以改变当前结论。

同一抗体的另一个专利公开文本、另一个 linker 变体，只更新关联记录，不重开 atlas。

## 当前状态（2026-11-04）

条件 1、2、4、5、6 已满足。**条件 3：** 第 5 轮审核做了最后一轮定向检索，只找到 US20250277046
（基于已有 LIN-18D1 的多价构建体）——按本文件定义，这是同一 lineage 的新构建体，**不是新的独立 binder lineage**，
因此不触发重开，已作为关联记录登记。

**结论：六项条件均已满足。** 第 5 轮审核判定 **APPROVE**，定位为
**Fn14 therapeutic epitope atlas v1 candidate**，允许合并。
